# History Quiz

An interactive American history quiz web app. Test your knowledge with multiple-choice questions, instant feedback, and a final score — all in a clean, single-screen interface.

## Features

- **Multiple-choice questions** on American history
- **Instant feedback** — see correct/incorrect answers as you go
- **Score tracking** with a results summary at the end
- **Zero dependencies** — one self-contained HTML file, no build step

## Quick Start

No install needed. Just open `index.html` in any modern browser:

```bash
open index.html
# or
python3 -m http.server 8000
# then visit http://localhost:8000
```
